## Proyecto: Plataforma de Sorteo de Viajes a Israel (Tierra Santa)

Sesión del 13 de abril 2026 donde se armó paso a paso el documento de cotización para un cliente.

### Flujo del proyecto
1. Landing page -> usuario llega y ve info del sorteo
2. Registro -> selecciona individual ($5 USD) o familiar ($8 USD)
3. Pago -> integración Mercado Pago
4. Post-registro -> equipo MKT le llama, explica paquetes (avión, hotel, transporte, recorrido Tierra Santa)
5. Upsell -> se agregan servicios extra al perfil, se cobra más
6. Sorteo -> se rifa entre registrados, ganador recibe el viaje
7. CRM/Admin -> sistema para gestionar todo

### Descripción final
Plataforma web para gestión integral de sorteos de viajes a Israel (Tierra Santa), con sistema de registro y pago en línea (individual o familiar), panel CRM para gestión de participantes, seguimiento de llamadas, control de pagos y ejecución de sorteos.

### Objetivos definidos
1. Landing Page (responsive, CTA, FAQ, galería)
2. Sistema de Registro y Pago (multi-paso, cálculo automático de tarifa, Mercado Pago, confirmación email/SMS)
3. Perfil del Participante (datos, acompañantes, servicios, historial pagos, estado sorteo)
4. Panel CRM/Administración (gestión participantes, seguimiento llamadas, control pagos, módulo sorteo, reportes)
5. Integración de Telefonía (VoIP/Twilio - cotización aparte)
6. Funcionalidades Técnicas (auth, responsive, API Mercado Pago, seguridad)
7. Soporte y Mantenimiento

### Alcance
- Fecha de entrega: 4-5 semanas desde pago del 50% de anticipo
- NO INCLUYE: Telefonía VoIP, app nativa, gestión directa con aerolíneas/hoteles, reportes avanzados descargables

### Términos y Condiciones
- 60 días soporte gratuito post-entrega
- Funcionalidad adicional se cotiza aparte
- Plan mensual de administración disponible
- Contenido del cliente en primeros 7 días
- 2 rondas de revisión en diseño incluidas
- **Entrega final solo al liquidar 100% del costo total**
